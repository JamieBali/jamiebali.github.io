Let me introduce you to a game called <a href="https://colordle.ryantanen.com/">Colordle</a>. Colordle is a simple game where you have to guess the name of a colour. The only clue you get is a percentage score of how close you were with your last guess (where 100% means you're spot on, and 0% means you're completely off).

## Okay, so triangulation?

Okay, so here's the news - trilateration won't work here. The reason is that Delta E 00 doesn't use euclidian distances for calculation. Instead, there's a component that penalises lightness, and compresses distances for highly saturated colours. The priority for Delta E 00 isn't actual colour difference, it's visible colour difference that a human would actually be able to see (more blue cones in the eyes, etc...) I'm not a colour theorist.

# Okay, the question you've all been BEGGING to ask.

Why did I write this in Javascript?

The answer is simple - bookmarklets. By inserting a bunch of javascript into a bookmark, you can run javascript commands directly against a page you're on.

{% highlight javascript %}
javascript:(function(){YOUR FUNCTION(s) GO HERE!!!})();
{% endhighlight %}

The idea here is that I can now make a bookmarklet that does the following: finds my guesses for Red Green and Blue (or Once in a Blue Moon, Lucky Grey, and Red Dit) and then uses those values to predict the hex code I need to insert.

Using the following function we can extract the percentage scores of our initial three guesses

{% highlight javascript %}
function getPercentage(rgb_object) {
    const candidates = document.querySelectorAll('.selected-color-contianer');

    const targetDiv = Array.from(candidates).find(div => {
        const bg = div.style.backgroundColor || getComputedStyle(div).backgroundColor;
        return bg === rgb_object;
    });

    if (!targetDiv) {
        console.error("No box found with that colour.");
        return null;
    }

    const h1 = targetDiv.querySelector('h1');
    if (!h1) return null;

    let split = h1.innerText.split("-")

    return split[split.length - 1].split("%")[0].trim();
}
{% endhighlight %}

And once we're done we can drop the HEX code into the search bar. Combined all together, and after a small amount of debugging, there is now officially a bookmarklet that automatically solves Colordle for you (assuming you've done Once in a Blue Moon, Lucky Grey, and Red Dit as your starting guesses).

# What about AI?

Hill  Climbing is an iterative optimisation technique where we attempt to find a maxima on a plane. In normal person talk, we keep trying combinations until we get the best one. In our case, we're trying to optimise 3 different values - the difference scores from the initial red, green, and blue guesses.

We can do this by first picking a central colour (something like #808080 or rgb(128,128,128)) and then progressively make changes to the values until we find an exact match. Alternatively, to reduce processing requirement (in continually converting RGB into LAB), we can perform the optimisation for the LAB values directly, and then convert back to RGB at the end.

This is probably what I would have done had a brute force approach not found me the correct answer instantly - that being said, I can only really test this once per day so unless it turns out this just doesn't work on tomorrow's Colordle then I guess we have another option to try.
